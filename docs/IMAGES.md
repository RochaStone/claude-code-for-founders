# Images in this repo

Every image here is generated by the kit itself. No photos, no real people, no screenshots of anyone's posts.
Re-make them all with `python3 scripts/make-readme-images.py` (the PNGs need Google Chrome).

| File | What it is | Made by |
|---|---|---|
| `docs/hero.png` | The README hero: a y2k-blog window, founders-kit.exe, with The Rocheverse Times front page inside, a sidebar, a hit counter and a marquee | `scripts/make-readme-images.py` |
| `docs/triptych.png` | The wallpaper in all three motifs, side by side: analog, cyberpunk, y2k-blog | `scripts/make-readme-images.py`, which runs `pink-terminal/make-wallpaper.py` three times |
| `docs/img/step-01.svg` to `step-05.svg` | Pixel step badges for every "Start here" (under 2 KB each) | `scripts/make-readme-images.py` |
| `docs/img/divider.svg` | A gold pixel hairline between README sections | `scripts/make-readme-images.py` |
| `docs/img/heart.svg` | The gold pixel heart on "If it goes wrong" | `scripts/make-readme-images.py` |
| `pink-terminal/wallpaper.svg` | The wallpaper in Rocha's default motif (analog) | `pink-terminal/make-wallpaper.py --date "27 Oct 2026"` from `examples/style.rocha-coded.json` |
